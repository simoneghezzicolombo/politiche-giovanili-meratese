# Fonti grezze

Questa cartella contiene esclusivamente file originali, non modificati.

## Istat

Lo script `scripts/02_istat_population.py` usa per default il file ufficiale:

`https://demo.istat.it/data/posas/POSAS_2024_it_Comuni.zip`

Il file può anche essere salvato qui manualmente e passato con `--input`.

## OpenBDAP / RGS

Scaricare dalla pagina **Finanza degli Enti Territoriali → Analizza → Lavora sui dati in formato elaborabile → Rendiconto** il file ufficiale del rendiconto 2024.

Pagina: `https://openbdap.rgs.mef.gov.it/it/FET/Analizza`

Non rinominare o modificare il file prima di conservarne una copia in questa cartella.
